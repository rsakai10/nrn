NetStim Noise Parameter Explanation
===================================

The :attr:`NetStim.noise` parameter controls the randomness of spike intervals generated by a :class:`NetStim` object.

- If ``noise=0``, spikes are delivered deterministically at intervals equal to :attr:`NetStim.interval`.
- If ``noise=1``, intervals between spikes follow an exponential distribution with mean :attr:`NetStim.interval`.
- For intermediate values, ``0 < noise < 1``, each inter-spike interval (ISI) is computed as:

  .. math::

     ISI = (1 - noise) \times interval + noise \times X

  where :math:`X` is an exponentially distributed random variable with mean :attr:`NetStim.interval`.

Thus, a fixed refractory period of length ``(1 - noise) * interval`` separates spikes, after which additional random delay with exponential distribution occurs.

**Note:**

.. note::
   The exponential distribution probability density function (PDF) is maximal at zero, meaning the most likely additional delay value is zero. Hence, intervals just exceed the fixed portion but can be longer due to randomness.

**HOC example:**

.. code-block:: hoc

    objref ns
    ns = new NetStim()
    ns.interval = 10
    ns.noise = 0.3  // ISI = 7 ms fixed + exponential with mean 3 ms

**Python example:**

.. code-block:: python

    from neuron import h
    ns = h.NetStim()
    ns.interval = 10
    ns.noise = 0.3  # deterministic 7 ms plus stochastic component with mean 3 ms
