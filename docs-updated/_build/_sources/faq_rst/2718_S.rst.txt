Changing Channel Densities Along a Section
=========================================

When using morphology imported from SWC files with irregular section lengths, it is common to want spatially varying channel densities along dendrites. Instead of subdividing sections manually, use range variables and the segment variable `x` to specify channel densities as a function of position along each section.

.. note::
   Increasing the number of segments (`nseg`) in a section improves spatial resolution but does not allow different densities by segment unless you assign them explicitly.

Example in HOC:

.. code-block:: hoc

   access dend[25]
   dend[25].nseg = 3
   dend[25].gnabar_hh(0.1) = 0.01   // density near start of section
   dend[25].gnabar_hh(0.5) = 0.05   // density at middle of section
   dend[25].gnabar_hh(0.9) = 0.09   // density near end of section

Equivalent Python example:

.. code-block:: python

   dend[25].nseg = 3
   for seg in dend[25]:
       x = seg.x  # position along section, 0 to 1
       seg.gnabar_hh = density_function(x)  # assign density as function of position

Use the syntax `for (x, 0)` in HOC to assign channel densities programmatically over position ranges.
