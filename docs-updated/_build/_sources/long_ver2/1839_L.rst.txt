NetStim Noise Parameter
=======================

The `noise` parameter of the :class:`NetStim` class controls the randomness of spike intervals generated by a NetStim object. It regulates the level of variability in the timing of spikes delivered to target cells.

Description
-----------

- When ``noise=0``: All spikes are generated at perfectly regular intervals equal to the specified `interval` (i.e., spikes occur at times ``n * interval``, where ``n`` is an integer). This corresponds to completely deterministic spike timing.

- When ``noise=1``: The inter-spike intervals (ISIs) follow a Poisson process, meaning intervals are drawn independently from an exponential (negative exponential) distribution with mean equal to `interval`. Each spike timing is fully stochastic.

- For intermediate values ``0 < noise < 1``: The interval between spikes consists of two components combined additively:

  .. math::

    ISI = (1 - noise) \times interval + noise \times X

  where :math:`X` is an exponentially distributed random variable with mean equal to `interval`. This means that the ISI has a fixed minimum duration of ``(1 - noise) * interval``, plus a variable component drawn from an exponential distribution scaled by ``noise * interval``.

Implications
------------

- The ISI probability density function (PDF) for a given spike has zero probability for values less than the fixed component:

  .. math::

    \text{PDF}(t) = 
    \begin{cases}
      0 & \text{for } t < (1 - noise) \times interval \\
      \frac{1}{noise \times interval}
      \exp\left(-\frac{t - (1 - noise) \times interval}{noise \times interval}\right) & \text{for } t \geq (1 - noise) \times interval
    \end{cases}

- This means there is a guaranteed minimum waiting time before the next spike can occur, and after that, the spike times are stochastic following the shifted exponential distribution.

- The "most likely" ISI value when considering the exponential component alone is zero, which is why the exponential PDF peaks at zero interval. However, because of the fixed minimum interval, the actual ISI cannot be less than ``(1 - noise) * interval``.

Usage Examples
--------------

Python:

.. code-block:: python

    from neuron import h

    stim = h.NetStim()
    stim.interval = 10    # mean interval of 10 ms
    stim.start = 0       # start time
    stim.noise = 0.3     # fractional noise: 30% random variability

    # This results in ISIs with minimum 7 ms (70% of interval)
    # plus exponentially distributed noise with mean 3 ms

HOC:

.. code-block:: hoc

    objref stim
    stim = new NetStim()
    stim.interval = 10
    stim.start = 0
    stim.noise = 0.3

Summary
-------

- ``noise=0`` yields perfectly regular spike trains.
- ``noise=1`` yields fully stochastic, Poisson-like spike trains.
- Intermediate noise values shift the ISI distribution between these extremes by introducing a fixed minimum interval plus an exponentially distributed stochastic component.

.. note::

  The random component of intervals requires that the random number generator used for NetStim is set appropriately (e.g., to the negative exponential distribution) if reproducible and independent streams are desired.
