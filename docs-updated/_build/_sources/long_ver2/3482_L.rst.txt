Action Potential Propagation Speed in NEURON
============================================

When simulating action potential (AP) propagation in neuronal models using NEURON, users may encounter unexpectedly slow conduction velocities compared to experimental or alternative simulation results. This document summarizes common factors influencing AP propagation speed and provides guidance for correct model setup and interpretation.

Typical Symptom
---------------
An example scenario is observing AP propagation speeds as low as 0.025 m/s, while expectations (from experimental data or other simulators like MATLAB) suggest speeds on the order of 0.5–2 m/s for unmyelinated neurons.


Key Determinants of AP Propagation Speed
----------------------------------------

1. **Morphology and Diameter**

   - AP propagation speed strongly depends on the *local* geometry of the axon or dendrite, especially its diameter.
   - Ensure that the section diameters in NEURON match those used in reference models, as diameter directly influences axial resistance and membrane capacitance.
   - Differences in morphology (branching, diameter tapering) can affect conduction velocity.

2. **Stimulation Protocol**

   - Use a brief stimulus pulse about twice threshold amplitude to initiate spikes.
   - Duration should not exceed approximately 0.1 ms; longer stimuli may inactivate sodium channels and activate potassium channels, slowing propagation.
   - Example in Python:
     .. code-block:: python

        stim = h.IClamp(soma(0.5))
        stim.delay = 1    # ms
        stim.dur = 0.1    # ms
        stim.amp = 0.5    # nA, adjust to ~2x threshold

3. **Spatial Discretization (nseg)**

   - The number of segments (:attr:`nseg`) determines the spatial resolution.
   - Too coarse a grid leads to numerical decoupling, causing artificially slow or no propagation.
   - Use the ``lambda_f`` method or manually increase :attr:`nseg`.
   - Example adjustment in Python:
     .. code-block:: python

        for sec in h.allsec():
            sec.nseg = int((sec.L / (0.1 * h.lambda_f(100)) + 0.9) // 2 * 2 + 1)  # odd number per section

4. **Temperature Setting**

   - Simulation temperature significantly affects channel kinetics and thus conduction velocity.
   - NEURON's default temperature is 6.3°C, which is lower than typical in vivo or in vitro experimental temperatures.
   - Set temperature explicitly to physiological values (e.g., 20–37°C).
   - Setting temperature in Python:
     .. code-block:: python

        from neuron import h
        h.celsius = 20  # degrees Celsius

5. **Channel Densities and Kinetics**

   - Verify that sodium (:attr:`gnabar_hh`) and potassium (:attr:`gkbar_hh`) conductance densities match literature or experimental data.
   - Incorrect channel densities alter spike amplitude and velocity.

6. **Measurement of Conduction Velocity**

   - To measure conduction velocity accurately, determine spike latency between two points at known distance.
   - Compare times at consistent spike features (e.g., peak dv/dt or voltage crossing a threshold), not just peak voltage times.
   - Use sufficiently long propagation distances to reduce relative timing errors.

Example Cell Setup with Hodgkin-Huxley Channels
-----------------------------------------------
This example shows setting up a pyramidal neuron morphology and Hodgkin-Huxley (HH) channels in Python using LFPy and NEURON:

.. code-block:: python

    import LFPy
    from neuron import h

    cell_parameters = {
        'morphology': 'pyramidal_morphology.hoc',
        'v_init': -65,
        'rm': 54000,  # membrane resistance in Ohm*cm2
        'passive': False,
        'nsegs_method': 'lambda_f',
        'lambda_f': 400,
        'timeres_NEURON': 2**-3,
        'timeres_python': 2**-3,
        'tstartms': 0,
        'tstopms': 50,
    }

    cell = LFPy.Cell(**cell_parameters)

    for i, sec in enumerate(cell.allseclist):
        sec.Ra = 75     # Ohm*cm
        if i == 0:
            sec.cm = 1.5  # uF/cm2 for soma
        else:
            sec.cm = 3    # uF/cm2 for dendrites/axon

        sec.insert('hh')
        sec.gnabar_hh = 0.083  # S/cm2
        sec.gkbar_hh = 0.03    # S/cm2
        sec.gl_hh = 0.0003     # S/cm2
        sec.ena = 55           # mV
        sec.ek = -72           # mV
        sec.el_hh = -49.3      # mV

    # Set physiological temperature
    h.celsius = 20

.. note::

   Always verify that your model parameters and morphology match your reference data exactly before comparing conduction velocities. Differences in any of these parameters can produce significant discrepancies.

Summary Checklist for Troubleshooting Slow AP Propagation
---------------------------------------------------------
- Confirm morphology and diameters are identical to reference.
- Ensure stimulus is brief (~0.1 ms) and suitably strong (~2x threshold).
- Increase spatial discretization by raising :attr:`nseg` or using ``lambda_f`` method.
- Set :attr:`h.celsius` to a physiological temperature.
- Verify channel densities and kinetics.
- Measure conduction velocity precisely over an appropriate distance using consistent criteria.
