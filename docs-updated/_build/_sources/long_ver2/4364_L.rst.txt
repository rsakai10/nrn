Ion Currents in the Hodgkin-Huxley (hh) Mechanism
====================================================

When using the `hh` mechanism in NEURON, such as by inserting it into a section with::

    axon.insert('hh')

the variables `ina` and `ik` represent the sodium and potassium transmembrane currents, respectively. Understanding their units and accessibility is important for interpreting simulation results.

Units of `ina` and `ik`
-----------------------

- The variables `ina` and `ik` correspond to current density measured **per unit membrane area**.
- Their units are **milliamperes per square centimeter (mA/cm²)**.
- Because these currents are defined as density values, they are normalized by the local membrane surface area of the segment.

Accessing `ina` and `ik` in Python and HOC
------------------------------------------

- Although the `hh` mechanism internally *calculates and writes* values to `ina` and `ik`, these variables are *not declared as RANGE* variables in the `hh.mod` file.
- As a result, **you cannot access `ina` or `ik` directly via Python attributes like `axon(0.5).hh.ina` or HOC**; attempting to do so will raise an attribute error.

Example in Python:  

.. code-block:: python

    from neuron import h
    axon = h.Section(name='axon')
    axon.insert('hh')
    h.finitialize(-65)
    # The following will raise an AttributeError:
    # print(axon(0.5).hh.ina)  

- However, segment variables `ina` and `ik` are accessible directly at the segment level without specifying the mechanism, e.g., `axon(0.5).ina` or `axon(0.5).ik`.

Example accessing current densities:

.. code-block:: python

    print(f"ina at axon(0.5): {axon(0.5).ina} mA/cm²")
    print(f"ik at axon(0.5): {axon(0.5).ik} mA/cm²")

Visibility of Leak Current `il`
-------------------------------

- The leak current `il` *is* declared as a `NONSPECIFIC_CURRENT` and *is* accessible as a RANGE variable.
- Therefore, you can access `il` directly via the mechanism:  

.. code-block:: python

    print(axon(0.5).hh.il)

Explanation of Declarations in `hh.mod` NEURON Block
----------------------------------------------------

The relevant declarations in the `hh.mod` file are:

- `USEION na READ ena WRITE ina`
- `USEION k READ ek WRITE ik`
- `NONSPECIFIC_CURRENT il`

The variables `ina` and `ik` are calculated and written by the mechanism but are **not RANGE** variables, so they do not appear as accessible mechanism variables in Python or HOC.

In contrast, `il` is a `NONSPECIFIC_CURRENT` and *is* declared RANGE by default, making it available for inspection.

Summary
-------

- `ina` and `ik` are **transmembrane ionic current densities** with units **mA/cm²**.
- These are **not accessible** as `hh` mechanism variables (e.g. `section(x).hh.ina`) because they are not RANGE variables.
- You can access them directly at the segment level as `section(x).ina` and `section(x).ik`.
- The leak current `il` is accessible via `section(x).hh.il` because it is declared as a `NONSPECIFIC_CURRENT` and RANGE.

.. note::

    To quantify sodium and potassium currents generated by the HH channels at a specific segment, use `segment.ina` and `segment.ik`, which provide the current densities in mA/cm² directly. This is typically sufficient for calculations involving ionic concentrations or charge balance.
