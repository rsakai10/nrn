Plotting Individual Ionic Currents from Multiple Mechanisms
============================================================

When multiple ion channel mechanisms contribute to currents of the same ion species (e.g., sodium currents from both a persistent sodium channel and the Hodgkin-Huxley sodium channel), these currents are all aggregated into the same ionic current variable (e.g., `ina`) in NEURON. This makes it difficult to plot or analyze the current from a specific mechanism separately.

This section explains how to define and record the current generated by an individual mechanism, even when it shares ion species with other mechanisms.

Problem Description
-------------------

Each NMODL mechanism that uses an ion (declared with the `USEION` statement) impacts the ion current variable (e.g., `ina`) in NEURON. However, the ionic current variable in NEURON is shared across all mechanisms that read or write that ion current. Hence, there is no default separate name for the ion current contributed by a specific mechanism.

For example, two sodium channels using `USEION na READ ena WRITE ina` both contribute to the total sodium current `ina` for each segment but do not expose distinct `ina` variables in hoc or Python.

Recommended Solution
--------------------

1. **Define an explicit variable to represent the mechanism's own current**

   In your `.mod` file, declare a separate variable (e.g., `i`) to hold the current for this mechanism.

2. **Make the variable accessible from hoc/Python by declaring it as a `RANGE` variable**

   This allows you to record or plot it directly.

3. **Calculate and assign the current to this variable inside the `BREAKPOINT` block**

   Also, assign the total ionic current (e.g., `ina`) to this variable to maintain ionic currents for charge balance.

Example: Persistent Sodium Current (.mod)

```mod
NEURON {
    SUFFIX nap
    USEION na READ ena WRITE ina
    RANGE g, gbar, i   : Conductances and channel current for this mechanism
    GLOBAL winf, tauw
}

ASSIGNED {
    v (mV)
    ena (mV)
    ina (mA/cm2)
    g (mho/cm2)
    gbar (mho/cm2)
    w
    winf
    tauw (ms)
    i (mA/cm2)      : Current of this mechanism, accessible for plotting
}

STATE {
    w
}

BREAKPOINT {
    SOLVE states METHOD cnexp
    g = gbar * w
    i = g * (v - ena)   : Store this mechanism's current
    ina = i             : Pass current to NEURON's total sodium current
}

INITIAL {
    : Initialize w, etc.
}

DERIVATIVE states {
    : Define equations for w
}
```

Key Points:

- The separate variable `i` stores the ionic current contributed by this mechanism.
- Declaring it as `RANGE` allows access via hoc or Python with the segment variable syntax, for example, `section(0.5).nap.i`.
- The total ionic current variable `ina` must still be assigned for NEURON's internal ion concentration and charge calculations.

Usage Example in Python
-----------------------

Suppose you have created a section `soma` with two mechanisms: Hodgkin-Huxley sodium (`hh`) and your persistent sodium (`nap`). You can record and plot their individual currents as follows:

```python
from neuron import h, gui
import matplotlib.pyplot as plt

soma = h.Section(name='soma')
soma.insert('hh')   # Contains hh Na current: hh ina
soma.insert('nap')  # Contains persistent Na current: nap i

stim = h.IClamp(soma(0.5))
stim.delay = 5
stim.dur = 1
stim.amp = 0.1

v_vec = h.Vector()
v_vec.record(soma(0.5)._ref_v)

hh_i_vec = h.Vector()
hh_i_vec.record(soma(0.5).hh._ref_ina)  # total hh sodium current

nap_i_vec = h.Vector()
nap_i_vec.record(soma(0.5).nap._ref_i)  # persistent Na current from nap mechanism

t_vec = h.Vector()
t_vec.record(h._ref_t)

h.finitialize(-65)
h.continuerun(40)

plt.figure()
plt.plot(t_vec, hh_i_vec, label='hh Na current (ina)')
plt.plot(t_vec, nap_i_vec, label='nap Na current (i)')
plt.xlabel('Time (ms)')
plt.ylabel('Current (mA/cm²)')
plt.legend()
plt.show()
```

This code records and plots the sodium current from both mechanisms separately.

Additional Recommendations
--------------------------

.. note::

   - Use simple and clear variable names within mechanisms. For conductances, use `g` and `gbar` rather than duplicating the suffix, e.g., avoid `gnap_bar_nap`.
   - Each mechanism namespace is independent; the same variable names may be used across mechanisms without conflict.
   - Always verify units using `modlunit` to ensure consistency.
   - Include an `INITIAL` block when necessary to initialize state variables.
   - Use `RANGE` variables when values need to be accessible or varied spatially.
   - When defining ionic currents with `USEION`, always assign the total ionic current variable (e.g., `ina`) in the `BREAKPOINT` to maintain charge balance and ion concentration updates in NEURON.

Summary
-------

To plot or retrieve the ionic current specific to a self-created mechanism that shares ion species with other mechanisms:

- Declare a separate `RANGE` variable in your `.mod` file (e.g., `i`).
- Calculate and assign the mechanism's ionic current to that variable in `BREAKPOINT`.
- Assign the total ionic current variable (e.g., `ina`) to the same value.
- Access and record that variable at the segment level (e.g., `section(0.5).mechanism._ref_i`).
- Plot or analyze it separately from other ionic currents.

This approach maintains correct total ionic currents for NEURON's internal calculations while exposing individual mechanism currents for user inspection and plotting.
