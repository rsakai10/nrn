Note

When using an IClamp stimulus in combination with variable time step integration (adaptive integration via cvode.active(1)()), setting the stimulus amplitude (IClamp.amp) to zero does not guarantee no effect on the membrane potential.

This occurs because the presence of an IClamp forces the integrator to reinitialize at the start (IClamp.del) and end (IClamp.del + IClamp.dur) of the stimulus interval, even if amplitude is zero. This changes integration time points and can cause small perturbations in the solution, affecting results such as phase-response curves.

To avoid this effect:

  • Use fixed time step integration (e.g., advance time with fadvance() in a loop),

  • or reduce perturbations by lowering the absolute error tolerance with cvode.atol() or adjusting state scaling via cvode.atolscale().

Additionally, consider using the SaveState facility to initialize simulations on a stable trajectory, minimizing the required simulation time with fixed steps.

cvode.active(0)  // disable variable time step integration
tstop = 100
while (t < tstop) {
  fadvance()
}

from neuron import h
h.cvode.active(0)  # disable variable time step integration
h.tstop = 100
while h.t < h.tstop:
    h.fadvance()
