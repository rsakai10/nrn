Chunked Simulation with h.CVode

When running a simulation in chunks using h.continuerun(), note that variable time step integration with h.CVode handles time differently than fixed step methods. For example, initializing time to negative values and advancing in chunks requires informing CVode of changes in time and states using h.CVode.re_init(). Otherwise, h.t may advance unexpectedly.

h.finitialize()
h.t = -stabilize_time
h.CVode().re_init()

for i in range(num_chunks):
    h.continuerun(h.t + chunk_time)
    if h.t >= 0:
        # write data
    h.frecord_init()

To avoid manual calls to h.CVode.re_init(), initialize time correctly at the start using an h.FInitializeHandler callback. Additionally, to ensure integration stops exactly at a desired time point with CVode, schedule an event at that time using h.CVode.event().

Note

Variable time step integration with CVode may advance h.t beyond the requested stop time after h.continuerun(); using events controls this behavior.

See also

h.continuerun(), h.CVode.re_init(), h.FInitializeHandler, h.CVode.event()
