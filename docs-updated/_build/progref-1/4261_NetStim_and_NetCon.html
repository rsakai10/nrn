NetStim and NetCon Usage in NEURON

This document addresses common questions about using NetCon and NetStim in NEURON, including how to input spike times and record outputs.

NetCon Source Variable and Spike Times

  • You cannot pass array elements (e.g., spike times) directly as a source variable to a NetCon.

  • If you have precalculated spike times, use the VecStim object (defined in vecevent.mod) to generate events from a vector of spike times.

Note

The VecStim mechanism allows you to input a set of spike times as a source for NetCon.

NetStim Output and Recording

  • NetStim generates events (spikes) at specified intervals or times.

  • The output of NetStim is not stored in a global variable.

  • To record spike times generated by NetStim, use the record() method of the NetCon object connected to the NetStim.

Using VecStim to Input Spike Times

Here is an example demonstrating how to use VecStim to input a set of spike times into a model:

import matplotlib.pyplot as plt
from neuron import h
from neuron.units import ms, mV

h.load_file('stdrun.hoc')

# Create a simple cell with Hodgkin-Huxley channels
soma = h.Section(name='soma')
soma.L = soma.diam = 10
soma.insert('hh')

# Create a synapse on the soma
syn = h.ExpSyn(soma(0.5))

# Define spike times (in ms)
spike_times = h.Vector([3 * ms, 10 * ms, 25 * ms])

# Create VecStim and play the spike times
try:
    vs = h.VecStim()
except AttributeError:
    raise Exception(
        "h.VecStim is not defined; did you forget to include and compile vecevent.mod?"
    )
vs.play(spike_times)

# Connect VecStim to synapse via NetCon
nc = h.NetCon(vs, syn)
nc.weight[0] = 0.004

# Record membrane potential and time
v = h.Vector().record(soma(0.5)._ref_v)
t = h.Vector().record(h._ref_t)

# Run simulation
h.finitialize(-65 * mV)
h.continuerun(50 * ms)

# Plot results
plt.plot(t, v)
plt.xlabel('Time (ms)')
plt.ylabel('Membrane potential (mV)')
plt.show()

Note

To use VecStim, you must include and compile vecevent.mod from NEURON’s source examples: https://raw.githubusercontent.com/neuronsimulator/nrn/master/share/examples/nrniv/netcon/vecevent.mod

Alternative: PatternStim

  • PatternStim is another built-in tool to specify spike patterns for multiple cells.

  • It can be more complex but allows specifying inputs to all cells in one command.

  • See NEURON documentation and examples for usage details.
