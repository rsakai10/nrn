Recording and analyzing the second derivative of an action potential

To record the second derivative (e.g. d²V/dt²) of an action potential in NEURON, do not compute derivatives inside a mod file. Instead, follow this workflow:

  1. Record the original variable (e.g. membrane potential v or capacitive current i_cap) to Vector objects during simulation.

  2. After running the simulation, compute derivatives using the Vector.deriv() method.

  3. Use separate procedures for simulation control and post-simulation analysis to ensure updated results after parameter changes.

Example HOC code snippet:

objref vvec, icvec, d2, g2

// Model and instrumentation (record v and i_cap)
soma vvec.record(&v(0.5))
soma icvec.record(&i_cap(0.5))

proc postprocess() {
    d2 = new Vector()
    d2.deriv(icvec, dt)   // compute derivative of i_cap
    if (g2 == nil) {
        g2 = new Graph(0)
    } else {
        g2.exec_menu("Erase")  // clear previous traces
    }
    d2.plot(g2, icvec)    // phase plot d2 vs icvec
    g2.size(-0.5, 0.5, -15, 15)
    g2.label(0.05, 0.9, "x: i_cap(0.5)")
    g2.label(0.05, 0.75, "y: D_t(i_cap(0.5))")
    g2.exec_menu("View = plot")
}

proc myrun() {
    run()
    postprocess()
}

Use run() to execute the simulation and then call postprocess() or encapsulate both in a procedure like myrun() to automate running and analysis.

Note

If simulation parameters change, calling myrun() updates recorded vectors and plots accordingly.
