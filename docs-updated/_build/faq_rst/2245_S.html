Why does setting gbar=0 still produce current?

When inserting a mechanism (e.g. kv) into multiple sections using a SectionList like dendritic, setting gbar_kv = 0 may not behave as expected because section lists can include unexpected sections:

dendritic { insert kv  gbar_kv = 0 }

may only act on the currently accessed section in the list rather than all dendrites, often defaulting to the soma, if it is included in dendritic.

To correctly set conductances only in dendrites, iterate explicitly:

forsec dendritic {
    insert kv
    gbar_kv = 0
}

If soma is included in dendritic, it can be checked and removed using:

dendritic_only = new SectionList()
forsec dendritic dendritic_only.append()
soma dendritic_only.remove()

Key points:

Note

  • A gbar value of zero means the channel produces no current in that section.

  • Inserting a mechanism into unintended sections may alter their conductances unexpectedly.

  • Use forsec() loops and verify section lists with commands like forsec dendritic ifsec "som*" print secname() to diagnose inclusion of soma.

  • Always confirm which sections are affected to match your modeling intentions.

This attention prevents misleading simulation results when modifying conductances in complex morphologies.
