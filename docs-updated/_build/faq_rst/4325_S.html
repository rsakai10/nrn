Initialization of Calcium Concentration with Point Processes and ion_style

When using calcium dynamics in a morphology with mechanisms that read and write calcium concentration (e.g. CaDynamics_E2), ion concentrations may not initialize as expected if attached point processes also read or write calcium ions.

Note

  • The internal (cai) and external (cao) calcium concentrations are by default initialized to NEURON’s global parameters

h.cai0_ca_ion (5.0e-5 mM) and h.cao0_ca_ion (2.0 mM) during h.finitialize(). - If a mechanism (e.g. CaDynamics_E2) lacks an INITIAL block setting cai, and does not WRITE cao, initial values come from these defaults. - Calling h.ion_style() with the cinit (initial concentration) parameter set to zero can be overridden by subsequent insertion of mechanisms reading cai, promoting the ion style and causing unintended re-initialization in specific segments.

To ensure consistent initialization of calcium concentrations:

  1. Modify your calcium dynamics NMODL (e.g., CaDynamics_E2.mod) to include initialization of cai:

    PARAMETER {
    cai0 = 1e-3 (mM)
    ...
}
INITIAL {
    cai = cai0
}

  2. For stability, consider using the derivimplicit method in the BREAKPOINT() block for calcium state variables.

  3. To control external calcium (cao) explicitly in your model:

    • Set h.cao0_ca_ion to the desired value (e.g., 1.2 mM) in your main Python or HOC file outside of cell class definitions:

      h.cao0_ca_ion = 1.2

    • Alternatively, extend the NMODL mechanism to WRITE cao, declare it as a STATE variable, initialize it in the INITIAL block, and fix it during simulation to avoid drift.

  4. Remove redundant calls to h.ion_style() if they conflict with the updated initialization scheme.

  5. When attaching a synaptic point process that reads cai and cao (e.g. a plastic synapse with a USEION statement), be aware that it may promote ion styles in particular segments, affecting initial calcium values locally.

See also

h.Section, h.ion_style(), h.finitialize(), NMODL USEION statement

This approach ensures that both intracellular and extracellular calcium concentrations are initialized consistently across all compartments and segments, avoiding unexpected local changes caused by point processes or ion style promotion.
