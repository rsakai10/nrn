Cutting a simulation into multiple runs with parameter changes in between

You can run a simulation in segments by calling h.continuerun() with increasing stop times. After the first segment finishes, modify parameters, then prepare to continue with:

if h.cvode.active():
    h.cvode.re_init()
else:
    h.fcurrent()

h.continuerun(new_tstop)  # new_tstop > previous stop time

To record variables across segments, define recording vectors before initialization and the first run:

soma_v = h.Vector().record(cell.soma(0.5)._ref_v)
t = h.Vector().record(h._ref_t)

h.finitialize(-65)
h.continuerun(300)

# modify parameters here

if h.cvode.active():
    h.cvode.re_init()
else:
    h.fcurrent()

h.continuerun(1000)  # continues from 300 to 1000 ms

Do not create new Vector recordings for the second segment; the original vectors accumulate the full trace.

If you want to discard values before continuing the second segment, call h.frecord_init() just before the second h.continuerun().

Note

Vector.record() must be called prior to simulation initialization.

See also

h.frecord_init(), h.continuerun(), CVode.re_init()
