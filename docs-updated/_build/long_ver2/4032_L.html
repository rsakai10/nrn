Multiple Values Assignment to Arrays in hoc and Python

When working with arrays or sequences of numeric values in NEURON’s hoc language, it is recommended to use the Vector class instead of plain C-style arrays (e.g., double arr[n]). The Vector class provides convenient methods for initialization, manipulation, and printing.

Assigning Multiple Values to a hoc Vector

To create and initialize a Vector with multiple values at once, follow these steps:

// Declare an objref to hold a Vector instance
objref length_neuron
// Create a new empty Vector
length_neuron = new Vector()
// Insert values starting at index 0; insrt arguments are the values
length_neuron.insrt(0, 40, 56, 64, 70)

You can then use

length_neuron.printf()

to display the stored values and the vector length.

This avoids element-wise assignment using loops and is more idiomatic in hoc.

Working with Python instead of hoc arrays

If you prefer the Python interface to NEURON, you can directly create and manipulate numpy arrays or Python lists to hold multiple values.

For example:

from neuron import h
import numpy as np

# Create a Python list or numpy array of neuron lengths
length_neuron = [40, 56, 64, 70]

# Convert Python list to hoc Vector if needed
vec = h.Vector(length_neuron)

Note that the hoc Vector and Python lists or numpy arrays can be converted back and forth for convenient manipulation.

Recommended Practices

  • Avoid using fixed-size C-style arrays in hoc (e.g., double arr[n]).

  • Use Vector methods like Vector.insrt() for initializing multiple values efficiently.

  • Use Vector.printf() to output contents for debugging.

  • When possible, prefer Python with NEURON’s Python interface for more flexible array manipulation.

Note

For detailed information about the hoc Vector class and its methods such as Vector.insrt() and Vector.printf(), see the NEURON Programmer’s Reference Manual on Vectors.
