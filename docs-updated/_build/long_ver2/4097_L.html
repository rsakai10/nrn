Extending a Single-Compartment Model to a Multi-Compartment Model

When extending a single-compartment Hodgkin-Huxley (HH) model to a multi-compartment model, it is important to understand the roles of various section properties and inserted mechanisms, and how their combination affects the model behavior.

Section Properties and Their Roles

  • Ra: The axial resistance of the section, representing the cytoplasmic resistance to current flow along the neurite.

  • cm: The membrane capacitance per unit area, representing how much charge the membrane can store.

These are not membrane mechanisms but properties of h.Section that must be assigned appropriately to each compartment to ensure correct passive electrical properties and axial coupling between sections.

Membrane Mechanisms

  • HH mechanism: Represents voltage-gated sodium and potassium channels used for action potential generation. Usually inserted in soma and axonal compartments.

  • pas mechanism: Represents passive leak conductance, typically inserted in dendritic compartments to model resting membrane properties and subthreshold behavior.

Typical Setup Example

For example, a multi-compartment model extending a single compartment HH model may be arranged as follows:

  • Soma: Set Ra, cm attributes and insert the modified HH mechanism with adjusted parameters.

  • Axon: Similarly, set Ra, cm and insert the same HH mechanism.

  • Apical and Basilar Dendrites: Set Ra, cm and insert the pas mechanism to represent passive properties.

Current Injection

Current stimulation is typically implemented by placing a h.IClamp (or another appropriate PointProcess) at the desired location to inject current into the model.

Resting Potential and Initialization Considerations

When combining mechanisms with different resting reversal potentials (e.g., HH default resting ~ -65 mV, passive leak with e_pas at -70 mV), the resulting model may not have a uniform resting potential. This causes the built-in initialization to not place the model in a steady resting state automatically.

Recommendation: Adjust reversal potentials consistently across compartments. For example, set e_pas to match the HH resting potential (e.g., -65 mV) in all dendritic compartments to avoid unstable or non-uniform resting potentials.

Example HOC Initialization:

```hoc forall {

Ra = 100 // axial resistance in Ohm-cm cm = 1 // membrane capacitance in uF/cm^2

}

soma {

insert hh // Adjusted HH parameters if applicable

}

axon {

insert hh // Adjusted HH parameters if applicable

}

apical {

insert pas e_pas = -65 // Match the HH resting potential g_pas = 0.001

}

basal {

insert pas e_pas = -65 g_pas = 0.001

}

// Insert current clamp at soma objref stim soma stim = new IClamp(0.5) stim.del = 100 stim.dur = 500 stim.amp = 0.1 ```

Example Python Initialization:

```python from neuron import h

for sec in h.allsec():

sec.Ra = 100 # Axial resistance in Ohm-cm sec.cm = 1 # Membrane capacitance in uF/cm2

soma = h.soma[0] axon = h.axon[0] apical = h.apical[0] basal = h.basal[0]

# Insert HH channels in soma and axon for sec in [soma, axon]:

sec.insert(‘hh’) # Adjust hh parameters if needed, e.g.: # sec.gnabar_hh = 0.12 # sec.gkbar_hh = 0.036

# Insert passive mechanism in dendrites for sec in [apical, basal]:

sec.insert(‘pas’) sec.e_pas = -65 # Set to HH resting potential to maintain uniform RMP sec.g_pas = 0.001

# Create current clamp at soma(0.5) stim = h.IClamp(soma(0.5)) stim.delay = 100 stim.dur = 500 stim.amp = 0.1 ```

Summary and Best Practices

  • Setting Ra and cm on each compartment models the neurite’s passive electrical properties and is essential for multi-compartment spatial modeling.

  • Insert voltage-dependent mechanisms (e.g., HH channels) where active properties are required (often soma and axon).

  • Insert passive leak (pas) in dendrites to appropriately model resting and subthreshold electrical behavior.

  • Ensure consistent reversal potentials, especially for mechanisms like pas, to achieve a stable and uniform resting membrane potential across all compartments.

  • Use current injection point processes such as h.IClamp to stimulate the model.

  • Initialize the model with consideration of spatial heterogeneity to ensure physiological relevance.

Note

Decisions on which mechanisms to include and their parameters should be guided by the scientific questions driving the modeling study. The complexity introduced by multi-compartmental structure should be justified by the necessity to answer these questions.
