Record and Print Recorded Data in NEURON

When recording variables during a simulation using Vector’s record() method, it is important to run the simulation before accessing or printing the recorded data.

Recording Data Using Vector

  1. Create Vector objects to store time and variable data:

objref rect, recv
rect = new Vector()
recv = new Vector()

  1. Set up recording of time and a variable (e.g., voltage at the middle of the soma):

recv.record(&SThcells[0].soma.v(0.5))
rect.record(&t)

  1. Run the simulation before trying to access the recorded data:

run()

  1. Print or access the recorded data after the simulation has run:

recv.printf()

Explanation

The record() method marks the Vector to record the referenced variable during the simulation run. However, the vector does not contain any data before simulation starts. Therefore, printing the vector immediately after calling record() but before running the simulation will result in an empty vector (often just outputting 0).

To avoid this:

  • Always call run() (in HOC) or h.run() (in Python) after setting up recording and before accessing recorded data.

  • You can then print or manipulate the vectors containing recorded data.

Example HOC code snippet:

objref rect, recv
rect = new Vector()
recv = new Vector()
recv.record(&SThcells[0].soma.v(0.5))
rect.record(&t)

run()

recv.printf()

Example Python code snippet:

from neuron import h

rect = h.Vector()
recv = h.Vector()

# Assuming SThcells is defined and has a soma section
recv.record(SThcells[0].soma(0.5)._ref_v)
rect.record(h._ref_t)

h.run()

recv.printf()

Note

The key point is that recording merely establishes a “listener” on the variable to save its value during simulation. Actual data appears in the vector only after the simulation advances in time via run().
