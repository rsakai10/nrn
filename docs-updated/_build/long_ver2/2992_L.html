Fano Factor Analysis of NetStim Events

This document explains how to analyze the stochastic spike times generated by NEURON’s NetStim with noise enabled, to verify that the spike counts follow a Poisson distribution, which should exhibit a Fano factor close to 1.

Background

The Fano factor is defined as the ratio of the variance to the mean of spike counts within fixed time intervals. It applies to discrete event counts, not to continuous variables such as interspike intervals (ISIs). For a Poisson process, the Fano factor equals 1.

When NetStim is configured with noise=1, it generates spike times as a renewal process with interspike intervals drawn from a negative exponential distribution. While the ISI distribution is continuous, the counts of spikes in equally sized time windows are Poisson distributed.

Incorrect Approach

A common mistake is to compute the Fano factor using interspike intervals directly, for example by dividing the variance of ISIs by their mean:

Vec1 = new Vector()
for i=1,(Vec.size()-1){
    Vec1.append(Vec.x[i] - Vec.x[i-1])
}
print Vec1.var()/Vec1.mean()

This yields a large value (much greater than 1) that does NOT represent the Fano factor because ISIs are continuous and the ratio of variances to means in ISIs does not correspond to the Fano factor.

Correct Procedure

  1. Record spike times produced by NetStim into a Vector.

  2. Divide the simulation interval into bins of fixed size (time windows).

  3. Count the number of spikes within each bin.

  4. Compute the variance and mean of these spike counts.

  5. Calculate the Fano factor as variance divided by mean of the binned spike counts.

Example HOC Code

This example sets up a NetStim generating noisy spike times and calculates the Fano factor based on counts in 20 ms bins:

objref sti, con, vec, hist
sti = new NetStim()
sti.interval = 100      // Mean interspike interval 100 ms
sti.start = 10         // Spike train starts at 10 ms
sti.number = 1e9       // Effectively unlimited number of spikes
sti.noise = 1          // Full noise (Poisson-like spike train)

con = new NetCon(sti, nil)
vec = new Vector()
con.record(vec)        // Record spike times from NetStim

tstop = 35000          // Simulation duration (ms)
load_file("stdgui.hoc") // Ensure standard run library loaded
cvode_active(1)        // Turn on variable time step integration for speed

run()

// Compute histogram of spike counts in 20 ms bins
hist = vec.histogram(0, tstop, 20)

// Calculate and print the Fano factor (variance/mean of spike counts)
print "Fano factor from spike counts in 20 ms bins: ", hist.var()/hist.mean()

// Optionally compute ISI statistics
objref isivec
isivec = new Vector()
isivec.deriv(vec, 1, 1)    // Compute ISIs from spike times using Euler method
print "Mean ISI:", isivec.mean()
print "Stddev ISI:", isivec.stdev()
print "CV (std/mean ISI):", isivec.stdev()/isivec.mean()

Notes

  • The Vector.histogram() method counts the number of spike events in successive bins over the simulation time.

  • The Fano factor is meaningful only when computed over spike counts in defined intervals, not from continuous ISIs.

  • Using Vector.deriv() on the spike times vector efficiently computes the ISI distribution.

  • Specifying a very large sti.number ensures that the spike train length is limited only by simulation time (tstop), not by the maximum spike count.

  • Enabling cvode_active(1) activates adaptive integration, speeding up the simulation when no biophysical model cells are involved (i.e., when just NetStim is used).

Additional Example for Fast Analysis

Here is a complete minimal example to run at the :hoc:`oc>` prompt:

load_file("stdgui.hoc")

objref sti, con, vec, hist, isivec
sti = new NetStim()
sti.interval = 100
sti.start = 10
sti.number = 1e9
sti.noise = 1

con = new NetCon(sti, nil)
vec = new Vector()
con.record(vec)

tstop = 35000
cvode_active(1)

run()

// Compute interspike intervals
isivec = new Vector()
isivec.deriv(vec, 1, 1)
print "Mean ISI:", isivec.mean()
print "ISI stddev:", isivec.stdev()
print "CV (ISI stddev/mean):", isivec.stdev()/isivec.mean()

// Compute Fano factor from spike counts in 20 ms bins
hist = vec.histogram(0, tstop, 20)
print "Fano factor (variance/mean of spike counts in 20 ms bins):", hist.var()/hist.mean()

Summary

  • The Fano factor measures variability of counts of spike events in time windows, not variability of intervals.

  • Use Vector.histogram() to bin spike counts and compute variance and mean for the Fano factor.

  • NetStim with noise=1 generates spike times as a Poisson process (interspike intervals are negative exponential distributed), so counts over fixed intervals show a Fano factor near 1.

Note

Always load the standard run library with load_file("stdgui.hoc") before using cvode_active() or event-driven simulations to ensure proper operation on all platforms.
